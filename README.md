# Twitch Dock Themes

Personalize os painéis da Twitch no OBS com as cores do seu tema, Obsidian, Obsidian Graphite ou uma paleta própria.

**Windows x64 · OBS Studio 30.0.0 a 32.2.2**

[Baixar](https://github.com/moska1m/twitch-dock-themes/releases/latest) · [Guia rápido](docs/GUIA.md) · [Relatar bug](https://github.com/moska1m/twitch-dock-themes/issues/new?template=bug.yml)

## Recursos

- Aparência independente para Chat, Atividades, Informações e Estatísticas.
- Densidade compacta ou confortável no Chat e nas Atividades.
- Presets salvos, importação e exportação.
- Mudanças instantâneas; **Salvar** confirma. Sair sem salvar restaura o visual anterior.

## Instalação

1. Baixe e extraia o **Windows.zip**.
2. Feche o OBS e execute `Install.ps1` no PowerShell.
3. Abra **Ferramentas → Twitch Dock Themes**.

Se houver erro de permissão, execute o instalador como administrador.
